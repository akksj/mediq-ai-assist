# About this project

I started MediQ because I kept watching doctors in small clinics near me struggle with the same two things every day:

- Patients write long, messy symptom messages on WhatsApp
- Doctors end up rewriting notes by hand after every visit

This is my attempt to reduce that friction a little.

It’s not a full hospital system. It’s a focused tool for neighborhood clinics that still run mostly on paper and phone calls.

I’m still learning, so the code isn’t perfect. If something feels rough, that’s because I built it while figuring things out.
